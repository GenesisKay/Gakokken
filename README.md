# Gakoken

Explorador de archivos rápido con indexación, para Android, Linux y Windows. Hecho con Flutter.

**Paquete:** `gakoken`
**applicationId:** `com.gakoken.gakoken`

## Correr

Android (emulador o teléfono), pasos completos en [`context/run.md`](context/run.md):

```powershell
$env:Path += ";$env:LOCALAPPDATA\Android\Sdk\platform-tools"
flutter pub get
flutter run
```

Contexto para agentes: [`context/context.md`](context/context.md).
